# Customer Support Knowledge Repository

## Description
This project is a knowledge repository for a real-world
Customer Support System.

It stores common customer problems, business rules, and
recommended solutions in a structured format.

## Files

- `knowledge_base.json` - Stores customer problems and solutions.
- `rules.txt` - Contains IF-THEN business rules.
- `support.py` - Python program for searching the knowledge base.
- `README.md` - Project documentation.

## Features

- Password reset assistance
- Payment failure assistance
- Order delay assistance
- Account lock assistance
- Rule-based solution retrieval

## Technology Used

- Python
- JSON
- GitHub

## How to Run

Run the following command:

```bash
python support.py
